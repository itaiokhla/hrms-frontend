Test images used by the face-attendance browser tests.

- `face-enrol.jpg`, `face-stream.mjpeg`: crop of the NASA portrait of astronaut
  Eileen Collins (public domain), as distributed in scikit-image's `astronaut`
  test image. The `.mjpeg` file is fed to Chrome as a fake webcam.
- `no-face.jpg`: scikit-image's `camera` test image (CC0); contains no
  detectable frontal face and is used for the rejection path.
